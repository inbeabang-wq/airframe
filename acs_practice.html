실제 시험 구성 (FAA MTG 기준) · 실기: Airframe 11개 프로젝트, 프로젝트마다 DME가 MTG 생성 질문 2개를 묻고 pass/fail 채점(작업을 잘해도 질문을 틀리면 그 프로젝트 불합격). 70%는 시험 전체에 적용 → 11개 중 8개 이상 통과, 재시험은 불합격 프로젝트만. · 구술: MTG 무작위 출제(DME 선택 불가), 최소 4문항 + AKTR에서 틀린 ACS 코드마다 1문항 → 최대 34문항, 70%는 구술시험 전체에 적용, 참고자료 사용 불가. 이 페이지는 ACS 요소마다 실기 과제(S)와 구술 문항(K·R)을 하나씩 만들어 MTG처럼 코드 단위로 연습하도록 구성했습니다.Actual test (FAA MTG): Practical — 11 Airframe projects, 2 MTG questions per project, pass/fail (a missed question fails the project); pass at least 8 of 11; only failed projects are retested. Oral — random MTG questions, minimum 4 plus 1 per ACS code missed on the AKTR, up to 34; 70% applies to the whole oral test; no references. This page gives one practice task or question per ACS element.
REF: 14 CFR §65.17, §65.75, §65.79 · FAA-S-ACS-1 Aviation Mechanic ACS · FAA Mechanic Test Generator FAQs (2023-05-22)

실기 모의시험 Practical — 11 projects, 2 questions each

MTG처럼 영역을 고르게 섞어 11개 과제를 무작위로 뽑습니다. 과제마다 작업 수행과 DME 질문 2개를 스스로 채점하세요. 셋 중 하나라도 ✗면 그 과제는 불합격, 8개 이상 통과해야 합격입니다.

구술 모의시험 Oral — minimum 4 + 1 per missed AKTR code (max 34)

기본 4문항에, 필기 결과표(AKTR)에서 틀린 ACS 코드를 넣으면 코드마다 1문항씩 더해집니다. 코드를 모르면 「추가 문항 수」로 정하세요. 70% 이상이면 합격입니다.
